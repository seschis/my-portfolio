A framework for reasoning about security in AI-generated code, based on a year of running coding agents against real and synthetic vulnerability prompts. The core finding: issues come in at least three structurally different tiers — unconditionally active priors, conditionally dormant knowledge, and knowledge gaps — and each tier calls for a different control, a different investment, and a different evaluation approach.
